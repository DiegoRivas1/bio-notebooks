# 02 Alineamiento de Secuencias

**Tema:** Alineamiento global y local de secuencias biológicas  
**Herramientas:** Python 3, numpy, matplotlib

## Qué aprenderás

- Implementar Needleman-Wunsch (alineamiento global) desde cero
- Implementar Smith-Waterman (alineamiento local) desde cero
- Visualizar matrices de scoring con heatmaps
- Comparar secuencias homólogas entre especies

## Algoritmos implementados

| Algoritmo | Tipo | Año | Uso principal |
|---|---|---|---|
| Needleman-Wunsch | Global | 1970 | Secuencias de longitud similar |
| Smith-Waterman | Local | 1981 | Encontrar regiones similares |
